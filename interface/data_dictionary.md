# Telemetry Data Dictionary & Interface Contract

## Overview
This document specifies the standard schema, field definitions, units, validation constraints, and missing-value handling rules for telemetry generated by the **Member 1: Workload Simulation and Monitoring** engine.

All downstream AI and optimization components must conform to this schema when ingesting, processing, or responding to telemetry datasets.

---

## Field Specifications

| Column Name | Type | Physical Unit | Permissible Range | Nullable | Missing Value Strategy | Description |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp` | `float` | Seconds (`s`) | `[0.0, ∞)` | **No** | Reject record | Relative simulation time or Unix epoch. Must be strictly monotonically increasing. |
| `request_rate_rps` | `float` | Requests/sec (`rps`) | `[0.0, ∞)` | **No** | Impute 0.0 | Instantaneous incoming traffic rate at this discrete time step. |
| `served_rate_rps` | `float` | Requests/sec (`rps`) | `[0.0, ∞)` | **No** | Impute 0.0 | Successfully processed and completed request throughput. |
| `dropped_rate_rps` | `float` | Requests/sec (`rps`) | `[0.0, ∞)` | **No** | Impute 0.0 | Rate of requests dropped due to queue saturation or timeouts. |
| `error_count` | `int` | Count | `[0, ∞)` | **No** | Impute 0 | Total requests discarded, timed out, or returned error status in the step. |
| `error_rate` | `float` | Ratio (`0.0 - 1.0`) | `[0.0, 1.0]` | **No** | Impute 0.0 | Ratio of failed/dropped requests relative to incoming load. |
| `latency_min_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | Minimum observed round-trip service latency in the interval. |
| `latency_mean_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | Arithmetic mean service latency in the interval. |
| `latency_p50_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | 50th percentile (median) request round-trip latency. |
| `latency_p90_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | 90th percentile request round-trip latency. |
| `latency_p95_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | 95th percentile request round-trip latency. |
| `latency_p99_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | 99th percentile (tail) request round-trip latency. |
| `latency_max_ms` | `float` | Milliseconds (`ms`) | `[0.0, ∞)` | **No** | Forward Fill | Peak observed round-trip latency in the interval. |
| `cpu_utilization_ratio` | `float` | Ratio (`0.0 - 1.0`) | `[0.0, 1.0]` | **No** | Forward Fill | Aggregate CPU cores utilization across active workers. |
| `memory_used_mb` | `float` | Megabytes (`MB`) | `[0.0, memory_total_mb]` | **No** | Forward Fill | Aggregate memory actively allocated by workers and buffer. |
| `memory_total_mb` | `float` | Megabytes (`MB`) | `(0.0, ∞)` | **No** | Forward Fill | Total allocated memory budget for the active cluster. |
| `memory_utilization_ratio` | `float` | Ratio (`0.0 - 1.0`) | `[0.0, 1.0]` | **No** | Forward Fill | Ratio `memory_used_mb / memory_total_mb`. |
| `allocated_cpu_cores` | `float` | Cores | `(0.0, ∞)` | **No** | Forward Fill | Total CPU compute cores allocated to provisioned workers. |
| `queue_depth` | `int` | Count | `[0, queue_max_capacity]`| **No** | Impute 0 | Number of pending requests currently waiting in the backlog. |
| `queue_max_capacity` | `int` | Count | `[1, ∞)` | **No** | Reject record | Maximum queue backlog threshold before drops occur. |
| `queue_wait_p95_sec` | `float` | Seconds (`s`) | `[0.0, ∞)` | **No** | Impute 0.0 | P95 time spent in queue before reaching a worker thread. |
| `queue_dropped_count` | `int` | Count | `[0, ∞)` | **No** | Impute 0 | Number of requests dropped by the queue during this step. |
| `queue_drop_reason` | `string`| Enum | See values below | **No** | `none` | Cause of drop: `none`, `queue_overflow`, `timeout`, `rejected`. |
| `workers_total` | `int` | Count | `[0, ∞)` | **No** | Forward Fill | Total provisioned worker instances. |
| `workers_ready` | `int` | Count | `[0, workers_total]` | **No** | Forward Fill | Workers active, idle, and awaiting incoming requests. |
| `workers_busy` | `int` | Count | `[0, workers_total]` | **No** | Forward Fill | Workers currently executing in-flight transactions. |
| `workers_initializing` | `int` | Count | `[0, workers_total]` | **No** | Impute 0 | Workers undergoing cold start or warm-up latency. |
| `workers_draining` | `int` | Count | `[0, workers_total]` | **No** | Impute 0 | Workers gracefully completing pending tasks before stopping. |
| `workers_capacity_rps` | `float` | Requests/sec (`rps`) | `[0.0, ∞)` | **No** | Forward Fill | Maximum instantaneous throughput capacity of ready workers. |

## Validation Constraints

1. **Latency Monotonicity:**
   $$\text{latency\_min\_ms} \le \text{latency\_p50\_ms} \le \text{latency\_p90\_ms} \le \text{latency\_p95\_ms} \le \text{latency\_p99\_ms} \le \text{latency\_max\_ms}$$
2. **Worker State Conservation:**
   $$\text{workers\_ready} + \text{workers\_busy} + \text{workers\_initializing} + \text{workers\_draining} \le \text{workers\_total}$$
3. **Queue Drop Consistency:**
   If $\text{queue\_dropped\_count} > 0$, then $\text{queue\_drop\_reason} \ne \text{"none"}$.
4. **Memory Bound:**
   $$\text{memory\_used\_mb} \le \text{memory\_total\_mb}$$
5. **Timestamp Sequence:**
   $$\text{timestamp}_{i} > \text{timestamp}_{i-1} \quad \forall i \ge 1$$
